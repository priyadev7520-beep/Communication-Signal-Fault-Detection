# Communication Signal Fault Detection using MATLAB

## Project Overview
This project detects faults in communication signals using MATLAB signal processing techniques.

## Features
- Signal generation
- Noise addition
- Fault simulation
- Fault detection
- FFT analysis
- CSV data export

## Technologies Used
- MATLAB
- Signal Processing
- FFT Analysis

## Output
- Fault detection graph
- FFT graph
- CSV output file

## How to Run
1. Open MATLAB
2. Open main.m
3. Click Run
